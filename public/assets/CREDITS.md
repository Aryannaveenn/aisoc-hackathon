# Asset credits

Every image and sound here is public domain or CC0, so no attribution is required. The sources are listed so the licences can be checked. Every jumpscare draws a face and a scream from a deck shuffled each game, so no two scares in a game match. Images were resized,, converted to greyscale and contrast-adjusted for the jumpscares.
